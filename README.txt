DEMO CATÁLOGO INTERACTIVO DECK LED

Abrir rápido:
1. Descomprimir la carpeta.
2. Abrir index.html con Chrome, Edge o Safari.

Para verlo como sitio local (recomendado):
- Abrir una terminal dentro de la carpeta.
- Ejecutar: python -m http.server 8000
- Entrar a: http://localhost:8000

Edición básica:
- Productos, precios, opciones y categorías: data.js
- Diseño visual: styles.css
- Comportamiento, partículas, WhatsApp y simulador: app.js

WhatsApp:
En data.js, completar brand.whatsapp con código de país y sin símbolos.
Ejemplo Argentina: 54911XXXXXXXX

Esta es una demo inicial. La siguiente etapa sería incorporar panel de administración, base de datos, login, carga de imágenes y publicación online.
